# Notes

**Assumptions**
- Pond radius 1.0 is the water; the 0.12 rim lies outside it.
- Lantern body sits on top of the standard (z 1.6 to 2.0).
- Only the left wall's frame casts faint (36%) shadows; the right wall's is a hairline, omitted.
- +y faces are grazing to the light, so they get no cast shadows. Plant shadows use bounding-sphere hulls.
- Generated by a script; the file itself is static.

**Verified (headless Chrome, 1600x1000 and 640x360)**
- Renders, no console errors, 250 KB, no forbidden resources.
- 40 px block blur: brightest block is a lantern (luma 216), sky max 176.
- Fronds cover about 7.7%, within x≤400, y≥726.

**Not verified**
- Other browsers, GPU frame timing.

**Known defects**
- Lamp 1 hides most of the tree trunk.
- Foliage is stylised.
